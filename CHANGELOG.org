* [2.0.0] - 2026-04-30

The 2.0.0 release marks the package's first stable, MELPA-targeted release.
The version was re-anchored from the 0.1.x development line to 2.0.0 to
signal API stability and reflect that =soft-narrow= is a from-scratch
re-implementation of the design originally explored by =fancy-narrow=
(which did not reach a stable 1.x line in this codebase).

** Highlights

- *Stackable narrowing with true intersection semantics.* Successive calls
  to =soft-narrow-to-region= push onto a buffer-local LIFO stack of
  =(start-marker . end-marker)= frames. The visible region is the
  intersection of every frame; =soft-narrow-widen= pops one frame.
- *Zero =defadvice=, minimal hook footprint.* Replaces fancy-narrow's
  =post-command-hook= + =defadvice= approach with =cursor-intangible=
  text properties for cursor restriction and =read-only= for edit
  protection. Hooks are added only while narrowing is active and removed
  immediately on the final widen.
- *Per-keystroke overhead minimised* via a cached intersection
  (=soft-narrow--cached-intersection=) and persistent overlays that are
  moved rather than re-created on every state change.
- *Boundary flicker eliminated* via a buffer-local =pre-command-hook=
  guard that suppresses movement commands which would cross a boundary,
  preventing the two-phase post-command correction from being visible.
- *Asymmetric stickiness* for boundary handling: the before-region uses
  =rear-nonsticky= + =front-sticky= on =cursor-intangible=, the
  after-region uses none, so the cursor can rest exactly at the end
  boundary while still being prevented from entering blocked text.
  Workaround for [[https://debbugs.gnu.org/cgi/bugreport.cgi?bug=51095][Emacs Bug#51095]].

** Added
- =soft-narrow-mode= as a global minor mode that rebinds the standard
  narrowing keys (=C-x n n=, =C-x n w=, =C-x n d=, =C-x n p=, =C-x n b=,
  =C-x n e=, =C-x n s=) to the soft-narrow equivalents.
- =soft-narrow-active-p= predicate for buffer-local narrowing detection.
- =soft-narrow-to-defun=, =soft-narrow-to-page=,
  =soft-narrow-org-to-block=, =soft-narrow-org-to-element=,
  =soft-narrow-org-to-subtree= as drop-in replacements for the standard
  Emacs / org-mode narrowing commands.
- =soft-narrow-lighter= customisation variable for the mode-line
  indicator (default =" *"=).
- =soft-narrow-blocked-face= customisable face for the visual deemphasis
  (light/dark variants).
- Comprehensive ERT test suite covering stack semantics, intersection,
  cursor-intangible boundaries, read-only protection, marker behaviour,
  performance regressions, stickiness, boundary guards, hook cleanup,
  and mode lifecycle.

** Changed
- *Minimum Emacs version raised to 29.1* (=Package-Requires=
  =((emacs "29.1"))=). The package now relies on
  =cursor-intangible-mode=, =defvar-local=, =if-let*=,
  =named-let=, and =defvar-keymap=, all of which require 29.1+.
- Visual deemphasis now uses overlays instead of font-lock-faces, which
  isolates the visual layer from any font-lock state in user buffers.
- Disabling =soft-narrow-mode= now widens every soft-narrowed buffer and
  destroys persistent overlays (clean shutdown).

** Removed
- =soft-narrow-bug-report= and =soft-narrow-version= helper commands —
  unconventional for MELPA packages, redundant given =M-x report-emacs-bug=
  and =package-version=.

** Fixed
- Cursor no longer flickers across narrowed-region boundaries during
  rapid movement commands.
- =cursor-intangible-mode= is correctly disabled when the final
  narrowing frame is popped (previously could remain enabled).
- =soft-narrow-widen= is harmless when no narrowing is active.
- Markers are explicitly nil'd out on widen to release buffer-local
  state.
